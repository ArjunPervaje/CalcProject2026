# +Chess

A Unity game that merges strategic chess gameplay with calculus concepts. This project was created as a final assignment for AP Calculus BC at Issaquah High School.

## Overview

+Chess challenges players to apply calculus principles while playing chess-inspired tactical gameplay. The game combines turn-based strategy with mathematical problem-solving to create a unique educational experience.

## Features

- Chess-inspired tactical gameplay
- Calculus-integrated mechanics
- Strategic decision-making
- Educational focus on AP Calculus concepts

## Installation

- Download the latest version under releases (Currently +Chess v1.0)
